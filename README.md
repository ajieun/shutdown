# 定时关机助手 (Shutdown Timer)

一个用 Python + Tkinter 写的桌面小工具：**倒计时关机 / 定时关机**，外加三个久坐办公用得上的**健康提醒**（喝水、提肛、走动）。

纯标准库实现，单个 `.py` 文件，支持 **Windows** 与 **macOS**（Intel / Apple Silicon），深色界面。

---

## 功能

### 关机
| 功能 | 说明 |
|---|---|
| 倒计时关机 | 8 个快捷时长（5 分钟 ~ 3 小时）+ 时/分/秒自定义输入，实时预览倒计时与预计执行时刻 |
| 定时关机 | 自绘图形化日历（可翻月翻年、今日高亮）+ 时间微调，常用日期与时间一键选择 |
| 动作切换 | 关机 / 重启 / 注销（macOS 为「退出登录」） |
| 系统级任务 | 勾选后写入系统计划，关闭本程序也能按时执行 |
| 随时取消 | 单个任务「取消该任务」、底部「取消全部关机任务」 |
| 状态持久化 | 计划与设置写入本地 `state.json`，重开程序自动恢复剩余时间 |
| 运行日志 | 带时间戳的日志页，同步写入日志文件，可一键打开目录 |

### 健康提醒
| 功能 | 说明 |
|---|---|
| 喝水提醒 | 间隔 5~240 分钟可调，每日目标杯数可设，大号倒计时 + 进度条，点「好的」累计杯数，跨天自动清零 |
| 提肛助手 | 收缩 / 放松秒数与组数可配，按「收缩 → 放松 → 下一组」自动推进，阶段提示音，训练完成弹窗，统计每日组数 |
| 走动提醒 | 久坐间隔 10~240 分钟、活动时长 1~30 分钟可配，到点进入「活动进行中」倒计时，结束自动计入次数与累计时长 |

提醒到点时会弹出**置顶提示窗**（可「好的」或「稍后 5 分钟」），并播放提示音。

## 运行环境

- **Python 3.8+**，仅依赖标准库 `tkinter`
- Windows 10 / 11
- macOS 10.13+（Intel 与 Apple Silicon 均可）

> macOS 注意：系统自带的 `/usr/bin/python3` **不含 tkinter**。请使用 [python.org 官方安装包](https://www.python.org/downloads/macos/)（universal2，M 系列芯片原生运行）或 `brew install python-tk@3.13`。

## 使用说明

### 1. 倒计时关机
切到「倒计时关机」页 → 点快捷时长或手动填时/分/秒 → 点「▶ 开始倒计时关机」。
启动后顶部横幅显示大号剩余时间与进度条，可随时取消。

### 2. 定时关机
切到「定时关机」页 → 点日期按钮打开日历选日期 → 设置时/分 → 点「▶ 开始定时关机」。

### 3. 健康提醒
切到「健康提醒」页，三个子页分别设置后点「开始提醒」。
底部状态栏会实时显示各提醒的剩余时间。

### 关于「系统级任务」
- **Windows**：调用 `shutdown.exe /t <秒>`，任务注册在系统里，关闭本程序依然生效；取消用 `shutdown /a`。
- **macOS**：启动一个独立后台 `osascript` 进程（内部 `delay` 后执行 AppleScript 关机），同样不依赖本程序存活；取消即终止该进程，进程号会写入状态文件，重开程序后仍可取消。

> macOS 首次执行关机/退出登录时，系统会请求「控制 System Events」的自动化权限，请在 *系统设置 → 隐私与安全性 → 自动化* 中允许，否则动作会被系统拦截（日志中会记录失败原因）。

## 常见问题

**Q：关闭程序后还会按时关机吗？**
勾选底部「同时设置系统级任务」后才会；不勾选时倒计时依赖程序本身运行（macOS 上没有 `shutdown /t` 这类系统延时机制）。

**Q：电脑睡眠了还会执行吗？**
系统级任务在 Windows 上由系统计时，睡眠会暂停计时；本程序自身的倒计时同理。需要严格守时的场景建议关闭睡眠。

**Q：macOS 上点执行没反应？**
检查是否授予了自动化权限；也可在「运行日志」页查看具体错误信息。

**Q：误设了关机怎么办？**
点「取消全部关机任务」；即使程序已关闭，重新打开后该按钮仍可取消残留任务。
